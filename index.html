Cara Order

Ikuti tiga langkah berikut untuk mengirim detail pesanan kepada admin AIZEA.

01

Pilih paket Robux

Pilih jumlah Robux pada katalog dan tekan tombol “Pilih paket”. Harga akan masuk ke ringkasan checkout.

02

Isi data akun

Masukkan username Roblox dengan benar dan pilih metode pembayaran manual yang diinginkan.

03

Konfirmasi via WhatsApp

Kirim pesanan ke admin. Admin akan mengonfirmasi detail pesanan dan memberikan instruksi pembayaran.

Pertanyaan Umum

Bagaimana cara memesan Robux?

Pilih paket, isi username Roblox, lalu tekan “Kirim Pesanan ke WhatsApp”. Admin akan membantu proses konfirmasi.

Apakah pembayaran otomatis?

Belum. Pembayaran AIZEA pada website ini dilakukan secara manual melalui instruksi admin setelah pesanan dikonfirmasi.

Apakah perlu memberikan password Roblox?

Tidak. Jangan pernah memberikan password, kode OTP, atau kode pemulihan akun Roblox kepada siapa pun.

Bagaimana jika paket yang dipilih salah?

Jangan lanjutkan pembayaran. Hubungi admin melalui WhatsApp untuk memperbaiki detail pesanan terlebih dahulu.
